## How to use this folder

**For retrieval, not for learning.**

NotebookLM is grounded in the sources listed in `sources.md`, so it is good at
answering *"what does this source say about X?"*. It knows nothing about this
repository's conventions, and nothing about Team Asterix's actual constraints.

Use it to find things. Then go and understand them somewhere else.

## Promoting something out of here

1. Read it.
2. Check it against the source it came from, not against your memory of it.
3. **Close the file.**
4. Write the explanation in your own words, into
   [02-concepts](../../02-concepts/) or wherever it belongs.
5. Delete the raw version, or leave it — but it stays in this folder either way.

**Step 3 is the one that matters.** If you cannot write it with the file closed, you
do not understand it yet. That is not a failure; it means the note is not ready, and
the right response is to read the source rather than to paste.

## What never happens

- Raw output does not get moved into a canonical folder.
- Raw output does not get "lightly edited" into a canonical folder.
- A concept page does not contain a paragraph that was generated and kept.

Not because generated text is always wrong — much of it is fine — but because a
repository where you cannot tell the difference is a repository you cannot trust, and
the trust is the only thing that makes a notebook like this worth keeping.
