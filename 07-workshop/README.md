## A note on how this folder is built

Nothing in here is named after a date or a year. This workshop runs once; the
knowledge is meant to be reused.

If it runs again, session content gets updated in place and git holds the history. No
`2026/` folder, no `v2/`. The moment the structure encodes a date, every future
reader has to work out which copy is current.
