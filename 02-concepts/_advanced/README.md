# Advanced Concepts

Topics that build on [the core concepts](../). Added as they come up — nothing here
is pre-created.

Likely candidates, roughly in the order they tend to be needed:

- State machines
- Protocols and message passing
- Event-driven systems
- Concurrency
- Reliability and fault tolerance
- Observability
- Scalability
- Security

Each becomes one file in this folder when it is actually written. No subfolders, no
placeholder files.

Larger future areas — distributed systems, cloud architecture, microservices, ROS 2,
embedded architecture, AI and agentic system architecture — go here too, **as files
first**. Only if one grows past a handful of files does it earn a subfolder. Creating
the subfolder first is how you end up with eight empty directories.
